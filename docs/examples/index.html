Six patterns we want to add — see what they could look like

The interactive PRD viewer is a work in progress. These six demos prototype patterns we considered but didn't ship in v0.1. Each opens standalone, runs offline, no server. If one feels right (or you can do better), open an issue or a PR.

  • 01

    Per-intent reading-progress rings

    A small SVG circle in each intent header fills as the reader dwells past it. Document gets a "73% read" footer aggregating the rings.

    →
  • 02

    Tufte sidenotes

    Margin-anchored notes for verifyCmd rationale and decision context. Float right at desktop, collapse to inline disclosure on mobile.

    →
  • 03

    Tangle-style scrubbable metrics

    Drag a number in prose to scrub its value; every dependent figure on the page recomputes live. Bret Victor's pattern, applied to budget and intent counts.

    →
  • 04

    Matuschak stacked columns

    Cmd-click a section anchor to push a new vertical column beside the current one instead of navigating away. Build a horizontal stack of side-by-side reading panes.

    →
  • 05

    Diff overlay against a prior revision

    Toggle "show changes since v0.3" — added paragraphs glow green, removed ones strike-through red. Same primitive Linear uses for project-doc revision compare.

    →
  • 06

    Inline edit + patch export

    Click any field to edit it inline; the page tracks deltas. "Download patch" produces a unified diff against canonical Plan.json. Editing-as-suggestion in pure HTML.

    →
Have ideas? The interactive PRD viewer is open WIP. If a pattern here matches a need (or you've seen better), file an issue at AdityaVG13/GPR/issues or send a PR — happy to merge thoughtful additions.
